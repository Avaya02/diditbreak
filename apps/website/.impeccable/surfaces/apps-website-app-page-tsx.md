# diditbreak website: landing page

Scope: the single marketing page of the Next.js site in `apps/website`. Visitor mode: Persuade.

Audience: individual developers using Claude Code who edit their own CLAUDE.md or skills. Job: understand in seconds that a context edit can make their agent worse or costlier, and that diditbreak measures it honestly. Action: copy `npx diditbreak init --demo` (primary); open GitHub (secondary). Proof: the real 12-run experiment from 2026-10-02 and the ETH Zurich study; nothing else is claimed. Constraints (user, binding): monochrome; dark and light sections mixed; no gradients; scroll-revealed motion; clean hero; straightforward copy; agent experiments only.

Memorable moment: the hero's split diff that applies itself, the CLAUDE.md change landing, then the agent's behaviour changing beneath it.
